DR. FALAK & MOHAMMAD SARIK — NIKAH INVITATION WEBSITE

FILES
- index.html: website content
- style.css: visual design and mobile layout
- script.js: envelope, music button, reveal heart, countdown

PREVIEW ON YOUR COMPUTER
1. Extract the ZIP folder.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Open index.html in your browser. If you have the VS Code Live Server extension, right-click index.html > Open with Live Server.

ADD THE MUSIC
The website is prepared to play a local file named aaj-sajeya.mp3.
Place a legally obtained/authorized MP3 in this same folder and keep the exact filename: aaj-sajeya.mp3.
Browsers usually require the visitor to tap the music button before audio plays. GitHub Pages will host the file if you upload it, but make sure you have permission to share the recording.

PUBLISH ON GITHUB PAGES
1. Sign in to https://github.com and create a new repository, e.g. falak-mohammad-nikah.
2. Set it to Public if you want guests to visit the site without logging in.
3. Upload index.html, style.css, script.js, README.txt and your authorized aaj-sajeya.mp3 (if used) to the repository's root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then click Save.
7. Wait a little, refresh the Pages screen, and open the published URL shown there. It usually looks like https://YOUR-USERNAME.github.io/falak-mohammad-nikah/
8. Test the link on your phone and share it with guests.
