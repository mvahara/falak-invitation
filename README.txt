FALAK & Sarik — LUXURY NIKAH INVITATION WEBSITE

FILES
- index.html       Opening envelope page
- invitation.html  Nikah invitation and venue link
- countdown.html   Countdown and heart reveal
- style.css        Website styling
- script.js        Shared JavaScript
- aaj-sajeya.mp3   Wedding music audio file

HOW TO OPEN
1. Extract all files from this ZIP into one folder.
2. Keep aaj-sajeya.mp3 in the same folder as the HTML files.
3. Open index.html in a browser to preview the website.
4. For public sharing, upload the extracted files together to a static website host (for example GitHub Pages).

MUSIC
The music player is configured to use aaj-sajeya.mp3. Browsers may block autoplay; if that happens, tap the play button. Keep the audio file in the same folder when hosting the site.

NOTE
The audio file was supplied by the user. Please make sure you have the necessary rights or permission to use and share it on a public website.
